# EcoNiño Perú

Prototipo educativo de economía sobre el impacto del Fenómeno El Niño en pequeños comercios del Perú.

## Funciones
- Registro de inventario con fotografías desde la cámara
- Simulador de pérdidas en escenarios leve, moderado y grave
- Recomendaciones preventivas
- Almacenamiento local en el navegador

## Ejecutar
Abrir `index.html` en un servidor local o publicar con GitHub Pages. Para cámara web usar HTTPS o localhost.

Los porcentajes son supuestos educativos, no pronósticos reales. Esta primera versión es estática y no utiliza Python ni base de datos remota.
